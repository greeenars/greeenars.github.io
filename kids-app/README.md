# あいぼうと せんかき（試作版）

幼児向け学習サブスクの最初の試作です。スマホのブラウザで動きます。

## できること
- あいぼう3体（こぐま／ショベルカー／にんじん）を選ぶ。種類ごとに背景の世界観が変わる
- 「しんか ずかん」で10段階のすがたを見られる（まだの段階はシルエット）
- あいぼうをタップするとはねる、指で撫でると喜ぶ
- 「せんかき」で ● から ★ まで線を引く（全8問）
  - 道からはずれると「まんなかを とおってね〜」と応援
  - 指を離しても、続きから再開できる
- クリアすると「みず」と「ごはん」がもらえる（1日5回まで）
- もらったものを指で引っぱってあいぼうにあげる → 10段階まで成長 → ずかん登録 → 次のあいぼうへ

## 試し方
GitHub Pages に反映後、スマホで `https://greeenars.github.io/kids-app/` を開きます。
「ホーム画面に追加」するとアプリのように全画面で使えます。

## ファイル構成
| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | 見た目と動き（アニメーション） |
| `characters.js` | 仮キャラの絵（本番は手描きの絵に差し替え） |
| `levels.js` | せんかきの問題と声かけのことば（ここに1行足すと問題が増える） |
| `app.js` | 動きの仕組み（保存・なでる・ドラッグ・線の判定） |
| `sw.js` / `manifest.webmanifest` | オフライン対応とホーム画面追加用 |

## 保護者向け
右下の歯車を2秒長押しすると、データを消して最初からやり直せます。

## 仮のもの（本番で差し替え予定）
- キャラクターの絵 → 資料「ゆるキャラ進化図鑑」に合わせてSVGで再現中。確定イラストに差し替え予定
- 声 → 端末の読み上げ機能を使用中。本番は録音した声
